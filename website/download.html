CatLogs

A local log viewer for Linux.

Installation

Choose one of the methods below. The quick install and binary download require no dependencies.

Method What it does Requires
Quick install Downloads binary + icon, creates desktop entry curl, root
Binary download Single standalone file, run from anywhere curl
.deb package Installs via dpkg with full desktop integration Debian/Ubuntu, root

Quick install (one command)

Downloads the installer script, which fetches the binary and icon, installs them to /usr/local/bin, and creates a .desktop entry.

copy$ curl -sSL https://catlogs.wassim.tech/install.sh | sudo bash

Binary download

Download standalone binary directly, no dependencies, everything bundled.

copy$ curl -sSL https://catlogs.wassim.tech/catlogs -o catlogs
$ chmod +x catlogs
$ ./catlogs

To install system-wide:

copy$ sudo mv catlogs /usr/local/bin/

Debian / Ubuntu package (.deb)

For Debian-based systems. Installs binary to /usr/bin, icon, and desktop entry. Uninstall with dpkg -r catlogs.

copy$ curl -sSL https://catlogs.wassim.tech/catlogs_1.2.0_amd64.deb -o catlogs.deb
$ sudo dpkg -i catlogs.deb

System Requirements

Operating system
Linux (any distribution - Debian, Ubuntu, Fedora, Arch, etc.)
For binary download
No dependencies. The standalone binary includes everything it needs.
Display
X11 or Wayland with XWayland. Minimum window size: 900x520 pixels.

Uninstalling

If installed via quick installer or binary download:

copy$ sudo rm /usr/local/bin/catlogs
$ sudo rm /usr/share/applications/catlogs.desktop
$ sudo rm /usr/share/icons/hicolor/256x256/apps/catlogs.png

If installed via .deb:

copy$ sudo dpkg -r catlogs
