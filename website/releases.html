Latest Release — v1.3.00

Released October 2026. The current stable release of CatLogs.

  • Fixed logical errors and edge cases across all core modules
  • Models: normalize tz-aware timestamps; fix PID serialization in to_dict()
  • Config: fix enabled_features merge; expand env vars in log path helpers
  • Crypto: respect XDG_CONFIG_HOME for key path; uid-scoped fallback in decrypt_data
  • Scanner: use CONFIG_DIR for db path; graceful unreadable-file handling
  • Log parsers: binary seek for large files; loosen year-rollback jitter to 2 days
  • Collectors: unified timestamp parsing; normalize tz-aware journalctl entries
  • GUI: fix delete-selected logic, signal selection dialog, process tree refresh, scanner error reporting, and running-tasks counter
